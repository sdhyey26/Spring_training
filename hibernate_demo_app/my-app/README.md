# My App

## Overview
This project is designed to provide functionalities for both customers and administrators. It is structured to separate concerns between customer and admin features, ensuring maintainability and scalability.

## Folder Structure
```
my-app
├── src
│   ├── admin
│   │   ├── controllers
│   │   ├── routes
│   │   └── services
│   ├── customer
│   │   ├── controllers
│   │   ├── routes
│   │   └── services
│   └── types
│       └── index.ts
├── package.json
├── tsconfig.json
└── README.md
```

## Installation
To install the necessary dependencies, run the following command:

```
npm install
```

## Usage
To start the application, use the following command:

```
npm start
```
